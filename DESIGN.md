# Noria homepage direction

The homepage uses the user-supplied minimalist video-hero brief. Older Y2K, Nad Pay, Pinterest, MonSkills and editorial-auction directions are superseded for this route.

## Visual system

- White editorial field with the supplied blue-violet pixel video overhead
- Video uses `object-cover` and a vertical `scaleY(-1)` transform
- White fade runs from transparent at 26.416% to white at 66.943%
- Geist is the utility and display sans
- Instrument Serif italic provides the single expressive phrase
- Main content begins at exactly 290px and stays inside a 1200px container
- Search uses a 40px capsule, pale surface and soft offset shadow
- Primary control is a tactile dark gradient button
- Existing black floating navbar remains unchanged

## Product truth

The hero promises agent discovery, comparison and bounded task drafts. It does not claim that Noria can execute, pay or hire an agent yet. Indexed totals and source proof come from 8004scan on BSC chain 56. Featured homepage agents are selected from the four required outcome searches rather than newest registry entries.

## Motion and accessibility

Motion staggers heading, description, search and source proof after mount while leaving content visible by default. Reduced-motion users receive a static poster and no entrance sequence. Search focus has a visible focus-within ring. Meaningful small text meets WCAG AA contrast.
