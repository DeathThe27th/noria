# Noria frontend direction

Noria uses a monochrome marketplace system across every route.

- Grayscale flipped video on the homepage
- Geist with Instrument Serif emphasis
- Left-aligned technical marketplace copy
- Black, white, and neutral gray only
- Top liquid-glass navigation with Home, Agents, Compare, and Tasks
- One hero action: Enter Marketplace
- Ask Noria floats at the lower-right on the landing page and becomes icon-only on mobile
- Agent directory, profiles, comparison, task creation, and task workspace inherit the same monochrome materials

Product language should resemble a crypto infrastructure marketplace: ERC-8004 identity, service endpoints, protocol support, feedback signals, onchain registration, permission windows, and bounded BNB exposure. Copy must remain understandable and must not imply execution, payment, or completed hiring.
