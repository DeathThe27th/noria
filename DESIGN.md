# Noria Design System

## Direction

Noria uses atmospheric financial intelligence: the immersive sky and floating entry of the first reference combined with the quiet editorial confidence of the second. Agents are signals on a horizon, not rows in a neon crypto dashboard.

## Palette

- Deep cobalt: `#123E82`
- Aerial blue: `#8FB9E4`
- Cloud ivory: `#F5F1E8`
- Midnight ink: `#182642`
- Plum accent: `#5D315F`
- Muted source text: `#71676F`

## Typography

- Editorial display and wordmark: self-hosted DM Serif Display, including italic.
- Product UI, evidence, navigation, and controls: self-hosted Manrope variable font, weights 200–800.
- Monospace is reserved for token IDs, addresses, chain records, and measurements.

## Composition

- Hero: full-bleed atmospheric cobalt/sky field with soft cloud depth and fine orbital paths.
- Navigation: restrained capsule control floating over the hero.
- Wordmark: lowercase `noria` in editorial italic serif; no permanent symbol is required yet.
- Search: a large, calm mandate instrument rather than a chat bubble.
- Featured record: a dark cobalt editorial panel using real 8004scan data.
- Lower product surfaces: ivory utility field with ruled comparisons, source evidence, and legible Manrope metadata.

## Components

- Agent cards read as indexed records with source IDs, chain standard, published description, evidence labels, source JSON, and Passport action.
- Agent Passports use provenance tables and declared-interface states.
- The AI concierge structures intent; it does not become the visual centerpiece or source of facts.
- Solid cobalt/plum controls carry primary actions. Ivory outlined controls are secondary.
- Rounded capsules are reserved for navigation and compact status, not every container.

## Truth and State

- `Indexed` means present in 8004scan, not active or available.
- Activity is `Reported active`, `Reported inactive`, or `Activity unknown`.
- Source failures and successful empty results are distinct states.
- Only endpoints explicitly verified by 8004scan become clickable; other HTTPS endpoints are shown as unverified hosts.
- Relevance measures exact normalized tokens in published source fields; it is never framed as performance.
- Missing evidence remains visibly missing.

## Responsive Rules

- Desktop uses the hero panel and wide evidence surfaces.
- Mobile keeps the wordmark, mandate input, category rail, featured record, and bounded catalogue legible in one vertical flow.
- All core controls support keyboard focus and visible error/disabled states.

## Motion

Motion remains sparse: atmosphere supplies depth, while controls use small position, border, and shadow changes. No ornamental neon glow or generic glass dashboard treatment.
